# Trademark policy

CropTop's source code is free software under the GNU General Public License v3.0 or later (see `LICENSE`). The license covers
the code. It does not grant rights to the **CropTop name, the CropTop logo or the app icon** (the "marks"), which identify the
official builds published by the CropTop project.

## What you may do without asking

- Use, study, modify and share the code under the GPL.
- Say that your project is "based on CropTop" or "a fork of CropTop", in plain text, as long as it is clear that it is not the
  official app.
- Use the name and logo to refer to the official CropTop app, for example in reviews, articles, tutorials or links to it.
- Build CropTop from source unchanged for your own use.

## What needs a different name

If you distribute a modified version — in an app store, as a download, or preinstalled — it must:

- use its own name, which must not contain "CropTop" or be confusingly similar to it;
- use its own icon and logo;
- use its own application id (not `app.croptop`);
- not suggest that the CropTop project made, endorses or supports it.

The code's copyright notices and license must stay, as the GPL requires; only the branding changes.

## Official builds

Official builds are published only by the CropTop project, signed with the project's key. Builds from anyone else are not
official, even if they are unmodified.

## Questions

If you are unsure whether a use is fine, open an issue and ask before publishing.
